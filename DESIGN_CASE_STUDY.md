# XNode LifeFlow AI — HyperBloom UX case study

## Problem
People juggle tasks, notes, projects and focus time across disconnected tools, creating unnecessary cognitive load.

## Target audience
Students, solo creators, hackathon participants and independent professionals who need a calm, responsive planning space.

## Design hypothesis
A unified, visually calm interface with clear actions and progressive disclosure can help users plan and complete everyday work.

## Core flows
1. Open the dashboard and review progress.
2. Add a task, mark it complete and see the updated completion rate.
3. Create a project or goal and update its progress.
4. Add an event to the calendar.
5. Choose a Pomodoro or break preset and start the focus timer.
6. Capture an idea in Notes.

## Visual system
Deep indigo sidebar, lavender and cyan gradients, nature-inspired imagery, rounded cards, typography hierarchy and soft surfaces. The selected XNode mark anchors brand recognition.

## Accessibility decisions
Semantic buttons, input labels, visible keyboard focus, responsive layout, reduced-motion media query and a contrast toggle.

## Honest scope
The planner is rule-based and clearly labelled DEMO. Storage is local to the browser. Charts and some overview examples are illustrative. These should not be represented as a connected AI or real usage data.

## Recommended judging demonstration
Show a task being created and completed, progress changing, project creation, calendar event creation, focus timer interaction and mobile layout. Explain the user problem and why the interface reduces friction.
